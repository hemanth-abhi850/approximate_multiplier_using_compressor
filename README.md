# Energy-Efficient Approximate Multiplier using Probability-Based Approximate 4:2 Compressor

This repository contains the Verilog implementation of an energy-efficient approximate multiplier using a novel **probability-based approximate 4:2 compressor**. The design is based on the following research paper:

> **"Energy Efficient Approximate Multiplier Design with Lesser Error Rate Using the Probability-Based Approximate 4:2 Compressor"**

---

## 🔍 Overview

This project presents a hardware design of an approximate multiplier that reduces power, delay, and area by using a probability-based approximate 4:2 compressor in the partial product reduction stage. It is suitable for error-tolerant applications such as:

- Image and video processing  
- Machine learning inference  
- Signal processing systems  

---

## 🧠 Key Features

- **Custom 4:2 Compressor:** Based on input probability to reduce complexity  
- **Approximate Multiplier Architecture:** Built using partial product generation + approximate reduction  
- **Error Metrics Analysis:** MAE, WCE, MSE, and NMED  
- **Synthesizable Verilog Code**  
- **Testbench for simulation**
